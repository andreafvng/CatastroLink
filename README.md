# CatastroLink

Recently, we experienced an earthquake that reminded us how quickly disaster can strike and how unprepared many of us are when it does. Last summer, many people were displaced from their homes due to wildfires and floods, forced to scramble for shelter and support. In these critical moments, emergency services can take time to respond, leaving individuals and families struggling to find safe accommodations. This experience inspired us to build CatastroLink—a tool that leverages community-driven efforts to provide real-time support and make sure no one faces disaster alone.

# What it does 🌍
CatastroLink is a web-based platform that enhances disaster response by:

Allowing users to report disasters in real time, creating a crowdsourced alert system.
Matching displaced victims (Clients) with volunteer Hosts offering shelter, using AI-powered logistics.
Providing live updates and coordination tools to help communities respond efficiently.
How we built it 🛠️
- Frontend: HTML
- Backend: Django
- Database: SQLite
- AI Matching and logistics: Gemini API

# Challenges ⚠️
Designing an efficient AI matching system that considers each users criteria
Creating a user-friendly interface that works even under stressful conditions.

# Accomplishments 🏆
Successfully implementing AI-driven host-client matching to optimize disaster response.
Building an intuitive crowdsourced disaster reporting system.
Creating a seamless user experience that encourages community participation.
Designing a platform that prioritizes safety, accessibility, and efficiency.

# What we learned 📚
The importance of real-time data processing in emergency response systems.
How to optimize AI algorithms for humanitarian applications.
The power of community-driven solutions in times of crisis.
How to build a system that remains scalable and resilient even under high demand.

# What's next for CatastroLink ⏭️
SMS-based disaster reporting to reach users with limited internet access.
Partnerships with local relief organizations to expand adoption.
Machine learning enhancements for more accurate matching and predictive analytics.
Mobile app development for easier accessibility and offline functionality.
